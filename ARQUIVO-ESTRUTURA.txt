🎯 PONTOS-CHAVE DA ARQUITETURA ATUAL

1. SEM BUILD PARA DEPLOY
   └─ Abre qualquer .html direto no navegador, sem servidor
   └─ O CSS do Tailwind já vai pré-gerado no repositório

2. TAILWIND COMPILADO PELO CLI (tailwindcss 3)
   └─ Config única em tailwind.config.js (paleta brand.*, darkMode 'class')
   └─ npm run build:css → assets/css/tailwind.css, linkado pelas 4 páginas
   └─ Classes precisam estar escritas por inteiro (sem concatenar em JS)

3. TEMA CLARO/ESCURO POR CLASSE (darkMode: 'class')
   └─ Script inline no <head> evita flash de tema errado
   └─ Botão de toggle + localStorage por página
   └─ Chave 'theme' unificada nas 4 páginas

4. IMAGENS QUE TROCAM POR TEMA
   └─ Padrão: dois <img>, um com dark:block hidden, outro com dark:hidden block

5. CARROSSEL CUSTOMIZADO NO HERO (index.html)
   └─ 2 imagens simultâneas empilhadas no desktop (≥1024px), trocando 1 por vez
   └─ 1 imagem revezando no tablet/mobile
   └─ Indicador de 3 pontos em verde-esmeralda
   └─ JS puro, sem lib de carrossel

═══════════════════════════════════════════════════════════════════════════════

🚀 COMO USAR

1. ABRIR NO NAVEGADOR
   └─ Basta abrir index.html (sem servidor necessário)

2. PERSONALIZAR CORES
   └─ Edite tailwind.config.js e rode npm run build:css
   └─ Mesmo vale ao usar qualquer classe Tailwind nova

3. ADICIONAR PÁGINA NOVA
   └─ Copie <head> + script de tema de uma página existente
   └─ Ajuste caminhos relativos de assets/
   └─ Sem duplicação: não existe, porque tudo já é duplicado por design atual

═══════════════════════════════════════════════════════════════════════════════

⚠️ DÉBITO TÉCNICO CONHECIDO (ver README.md para detalhes)

1. Overrides de tema e JS duplicados entre as 4 páginas — mudança de tema
   precisa ser replicada manualmente em cada arquivo.
2. assets/css/style.css e a fonte Handel Gothic D estão órfãos (não
   referenciados por nenhum HTML).
3. Sem compressão de imagem; tailwind.css precisa ser regerado à mão
   (npm run build:css) a cada classe nova.

Nenhum item é urgente; todos são candidatos a uma refatoração futura SE o
usuário decidir que vale o tempo (ver conversa: decisão consciente de manter
como está por enquanto).
